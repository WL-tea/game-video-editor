# 视频样本研究记录

本文件记录从公开视频归纳规则时实际覆盖了什么，以及哪些结论没有证据支持。它是研究审计记录，不是平台表现结论。

## 2026-07-26 首轮研究

### 覆盖方法

- 先用公开页面筛选候选，再下载无需登录即可访问的公开版本；没有读取浏览器 Cookie。
- 用 `ffprobe` 核对每个本地文件的实际总时长。
- 对 00:00 到文件结尾生成每秒一帧的顺序故事板并逐页检查，同时对完整视频运行场景变化检测，避免只看开头、缩略图或平台简介。
- 对含口播的样本转写完整音轨，并把转写与画面顺序交叉核对；无口播或以音乐为主的样本不根据错误转写推断内容。
- 研究文件只存放在仓库外的 E 盘临时目录，没有加入 Git。

这种方法覆盖完整时间线、主要画面变化和可识别语音，但每秒故事板仍可能漏掉不足一秒的单帧梗。因此，本轮只固化跨长区间可重复观察到的结构，不建立具体素材清单，也不声称完成逐帧版权审查。

### 已采纳样本

#### 美式鬼畜

1. [《原神.exe【美式鬼畜】》](https://www.bilibili.com/video/BV1iv411M7yk/) — 06:57，神拽拽de币乐。
2. [《美式鬼畜（确信）：恐怖游戏.exe》](https://www.bilibili.com/video/BV1fP4y1P7cZ/) — 04:19，萌哥坑坑哒。

观察：

- 两支视频都以可读的原玩法或连续口播为底层，把反应图、爆炸、测试卡、色偏、放大和突发音效集中放在事件峰值，而不是持续覆盖全部画面。
- 同一视频会复用少量反应元素，形成稳定的“灾难”“误判”“段落断裂”等语义；笑点来自元素与当前事件的对应关系，而不是素材数量本身。
- 爆点常呈短簇出现，随后回到原玩法。高密度来自峰值之间的对比，而不是取消所有安静段。
- 自动场景变化检测只能作为相对密度线索，不能等同于人工剪切数；在相同阈值下，两支样本约为每分钟 40 次和 30 次明显视觉突变，支持两者都明显高于本轮克制型《蔚蓝》样本，但不构成通用目标值。
- 具体影视片段、反应图和音乐可能涉及第三方权利，本技能只采纳结构，不默认复制素材。

#### 《蔚蓝》

1. [《蔚蓝 celeste 三分钟带你学会新手基础教学和进阶教学》](https://www.bilibili.com/video/BV1dJ411W7PD/) P1 基础教学 — 01:27，P2 进阶技巧 — 02:01，法拉拉Astral。
2. [《celeste 蔚蓝 C 面一至八章全流程（完结）》](https://www.bilibili.com/video/BV1hV411y7xV/) P1 第一章 C 面 — 01:15，P7 第七章 C 面 — 01:42，8bit的星与海。

观察：

- 技巧教学用短字幕直接配合对应操作画面，按技巧切换示例，不依赖长篇口播；画面承担演示，字幕只补充输入和条件。
- C 面样本保留从关卡开始到爱心或完成反馈的连续成功过程。其价值在于路线本身和完成证据，额外包装很少。
- 挑战视频需要开头的关卡身份与结尾的明确完成反馈；对决定性成功段任意切碎，会同时损伤情绪回报和可信度。
- 第一章和第七章 C 面的节奏差异主要来自关卡本身，说明剪辑密度不应覆盖关卡原有的速度、音乐和空间阅读。

### 已完整检查但不采纳

- [《【Celeste 蔚蓝】蔚蓝 Bingo 是什么？蔚蓝 Bingo 规则简单教学》](https://www.bilibili.com/video/BV14G4y1Y7uL/) — 13:36，azaazazaaz。视频已覆盖到结尾，但大量时间展示桌面、配置窗口和文字文档，信息层级与画面聚焦不适合作为本技能的“优秀剪辑”正面样本。它只提醒我们：录制工具界面、文档和游戏画面混在一起时，必须另做裁切、重排和重点突出。

### 未纳入的候选

首轮搜索得到的 YouTube 候选因公开播放器和下载端触发站点人机验证，无法在不读取登录状态的前提下完整播放。它们没有被计入已观看样本，也没有用于生成规则。后续只有在能够合法、完整覆盖时才补充研究记录。

## 使用边界

- 样本播放量只用于帮助筛选，不证明某种剪辑方法导致了表现。
- 本轮样本数量少，结论是首轮可执行假设；必须用用户自己的《蔚蓝》长录像和投稿数据继续验证。
- 新研究若推翻本轮结论，优先修改对应游戏或风格配置，并在本文件追加日期、样本和变更原因。

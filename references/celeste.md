# 《蔚蓝》游戏配置

处理 *Celeste*／《蔚蓝》录像时使用本配置。

## 素材特征

- 重复尝试如果没有压缩或进度变化，容易显得单调。
- 失败、重开、险些成功、通过房间、死亡次数、耗时和路线改进，是主要的可观察叙事信号。
- 精确移动很重要。保留足够的操作前摇，让观众看懂路线为何失败或成功。
- 干净的成功过程依赖此前失败形成反差，不要无故把最终成功切得过碎。
- 没有口播时，可用字幕和计数器建立连续性，但游戏事件仍然是主体。

## 寻找高价值时刻

标记：

- 第一次能解释障碍机制的失败；
- 具有明显规律的重复失败；
- 不寻常或视觉上荒诞的死亡；
- 路线、时机或推进距离的改善；
- 假胜利以及安全点前的死亡；
- 突破性的输入方式或路线变化；
- 最终成功及其直接余波；
- 进入更难房间、适合作为结尾反转的时刻。

压缩没有新增信息的重复尝试。只有当某次尝试能升级笑点、表现进步、建立回收梗或增强胜利回报时才保留。

## 无口播处理

优先使用简短的情境文字：

- 尝试次数和死亡计数；
- 逐渐变得荒诞的中性标签；
- “路线验证”“稳定复现”等伪技术表达；
- 画面难以理解时的简短目标提示。

避免长篇第一人称独白、过早塑造人设，以及仅仅重复画面内容的字幕。

## 默认叙事结构

选择一种：

1. **失败阶梯：** 可理解的失败 → 规律重复 → 更糟变体 → 险些成功 → 干净通关。
2. **虚假掌握：** 早期自信 → 立即打脸 → 反复“证明” → 真正突破 → 克制收尾。
3. **实验报告：** 明确目标 → 预测次数 → 数据不断恶化 → 出现异常 → 验证成功。
4. **单房挑战：** 说明一个限制 → 压缩尝试 → 展示进步 → 保留最终完整过程。

除非素材能够证明，否则不要暗示高水平操作、速通纪录或不存在的挑战规则。

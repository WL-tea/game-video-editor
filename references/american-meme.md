# 美式鬼畜风格

进行高密度 MLG／美式鬼畜试水，并只保留少量情境自嘲时使用本配置。

## 观众承诺

利用游戏中的失败、反转和夸张反应制造即时视听刺激。相较完整叙事，更重视逐时刻的娱乐性，但始终保留一个看得懂的目标。

## 剪辑规则

- 用最离谱的失败、险些成功或视觉矛盾开场。
- 快速说明目标，不做自我介绍。
- 把可读的原玩法作为底层，让高密度效果集中在失败、命中、误判、掉落、奖励和对话反转等事件峰值；不要把整条视频做成同一强度。
- 在能增强笑点时使用硬切、快速放大、定格、短重复、突然静音、失真强调和故意错位的声音；变速只作为提案，获得用户对具体区间的明确批准后再执行。
- 建立小型升级链：正常事件 → 强调重放 → 荒诞变体。
- 保持字幕短小。第一人称只用于当前情境中的抱怨、自嘲或嘴硬。
- 在单条视频中重复少量固定元素，并给它们分配稳定语义，例如爆炸表示灾难、测试卡表示段落断裂、同一反应图表示再次误判；回收时可以升级，但不要随机换梗。
- 突然结束或反高潮能够完成笑点时，可以采用。

## 节奏单元

优先按以下单元组织，而不是逐秒堆效果：

1. **建立可读性：** 保留足够的原玩法、原对话或环境声音，让观众知道正在做什么。
2. **等待触发：** 让动作或台词自然走到失败、命中、误判或反转点。
3. **爆点簇：** 在短区间内组合一次主强调与必要的补充反应，例如放大加撞击声，或定格加短覆盖素材。
4. **回到玩法：** 及时清掉覆盖层，恢复目标和空间关系，为下一次触发重新积累对比。

同一爆点簇内的效果必须围绕同一个事件。若删掉外部梗后仍看不懂发生了什么，先补足原事件，不要继续加料。

## 画面与声音分工

- 小字幕承担即时吐槽；全屏标题卡承担章节切换、引用或反高潮，不要让两者同时解释同一句话。
- 局部放大、色偏、速度线和反应图用于指向画面中的具体异常；尽量不要遮住角色、障碍或判定结果。
- 音效充当标点而不是持续底噪。口播存在时先保证完整句子可懂，再在句尾、停顿或动作落点加效果。
- 原音乐或游戏音已经提供节奏时，不要再铺一层互相竞争的常驻声音；需要强对比时可短暂抽空，再恢复声音。
- 允许一段干净玩法后连续出现多个爆点；不要把“高密度”误解为每一秒都必须出现新素材。

## 边界

- 关键时刻不要遮住障碍、角色位置或失败原因。
- 不要持续使用同一种最高强度效果。
- 第三方梗素材不要比游戏事件更长、更抢眼。
- 优先使用已获许可、原创、符合平台规范或方便替换的音视频素材。
- 只复用节奏和语义结构，不复刻第三方视频中的具体反应图、影视片段、音乐或素材包。
- 风格选择不等于变速授权。即使目标是高密度美式鬼畜，粗剪仍默认全片 `1.0x`。
- 避免反复发表个人宣言、自我介绍或索取关注。

## 胜利处理

明确选择一种：

- **喜剧性否认：** 淡化胜利，然后用下一次失败结束。
- **短暂释放：** 决定性操作阶段减少效果，成功时释放音乐，再补一个短回收梗。

不要用无关覆盖素材埋掉唯一的成功过程。

## 审核问题

- 新观众能否说出当前目标？
- 每个主要效果是否放大了一个真实事件？
- 每个爆点簇是否只有一个清楚的中心事件？
- 爆点之后是否及时回到可读的原玩法？
- 是否存在安静或干净的对比段落？
- 不认识所有外部梗的观众是否仍能理解笑点？

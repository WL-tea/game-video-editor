# 风格对照实验

比较美式鬼畜与结构化冷幽默时使用本流程，不要把单次投稿当作风格结论。

## 初始设计

条件允许时交替发布：

`A1 → B1 → A2 → B2 → A3 → B3`

- **A：** 美式鬼畜，包含少量情境自嘲。
- **B：** 事件主导的结构化冷幽默。

使用不同但大致可比的游戏片段。不要为了形式上的 A/B 测试重复投稿近似成片。

## 控制变量

尽量保持以下因素可比：

- 挑战是否容易理解，以及素材质量；
- 标题和封面的投入程度；
- 目标观众、发布平台、画面比例和声音质量；
- 条件允许时的发布时间；
- 游戏事件的新鲜度和难度。

记录无法控制的差异，不要把所有表现差异都归因于剪辑风格。

## 每次投稿记录

- 标题、封面构想、时长、发布时间和风格；
- 制作工时和素材成本；
- 可获得时的曝光量和点击率；
- 前段留存、平均观看时长、平均观看比例和完播率；
- 每次播放对应的点赞、投币、收藏、评论、分享和新增关注；
- 观众对难懂、疲劳、笑点和结尾回报的定性反馈。

优先使用创作者后台指标，不要只看公开播放量。

## 解释结果

- 比较中位表现和重复规律，不只比较最高播放的一条。
- 把标题封面的表现与视频内部留存分开分析。
- 把制作时间视为约束：表现略好但成本高出数倍的风格可能不适合持续生产。
- A 的前段留存更好但关注或满意度更差时，测试“结构化铺垫＋局部密集鬼畜”的混合方案。
- B 的留存不错但点击较弱时，先调整标题、封面和开场，再考虑放弃该风格。

## 每轮迭代输出

每完成一组 A/B，输出：

1. 已观察到的差异；
2. 可能原因及其他解释；
3. 下一组只修改一至两个变量；
4. 本轮继续保持不变的规则；
5. 是否有经过验证的规律值得写回对应风格配置。
